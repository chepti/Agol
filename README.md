# מסע כתב היד — לימוד קריאת כתב עגול

משחק לימוד לקריאת כתב יד עברי (כתב עגול): מסע מדורג של 13 תחנות,
מהאותיות הפשוטות לכתיבה (י ו ן) ועד קריאה שוטפת של סיפור שלם.

**כתובת חיה:** https://chepti.com/agol/

אח של [מסע כתב רש"י](https://github.com/chepti/Rashi) — אותו מנוע, תוכן וסדר אותיות חדשים.

## סדר הלמידה (לפי קלות הכתיבה)

י,ו,ן ← נ,ר,ה ← ח,ק,ת ← ס,כ(+ך),א ← ב,ג,ד ← מ,ם ← ע,ט,ש ← ז ← ל ← פ,ף ← צ,ץ

כל פעילות משתמשת רק באותיות שכבר נלמדו. אימות אוטומטי:

```bash
cd app && node scripts/validate-gating.mjs
```

## מה יש כאן

- **צד תלמיד** — מפת מסע מאוירת, 8 סוגי משחקים (כרטיסי היכרות, תמלול,
  חידונים, תפזורות, התאמה, זיכרון, סיפור עם קו מפריד דפוס/כתב-יד, ציור לפי הוראות),
  כוכבים, צלילים וקונפטי. כניסת תלמיד: קוד כיתה + שם + אימוג'י.
- **צד מורה** — הרשמה עצמית, כיתות עם קוד הצטרפות, מפת חום שליטה פר-אות.
- **פונט** — Ktiva Tama (כתב עגול) לכתב היד; Varela Round לממשק ולכתב דפוס. ניקוד ניתן לכיבוי/הדלקה (אורח ומורה).

## מבנה ופיתוח

```
app/  — Vite + React + TypeScript (RTL). התוכן: src/data/units.ts
api/  — PHP + SQLite (בסיס נתונים נוצר אוטומטית ב-~/agol_data)
```

```bash
cd app && npm install && npm run dev
```
