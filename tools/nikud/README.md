# עורך ניקוד מקומי (חד־פעמי)

כלי לעריכת מיקומי ניקוד על גופן Ktiva/Agol. **לא נפרס לאתר** — רק מקומי.

## למה 3 עוגנים ולא כל סימן בנפרד?

ב־OpenType כל סימני הניקוד «מתחת» (פתח, קמץ, חיריק…) נצמדים לאותו עוגן על האות.
מספיק למקם לכל אות:
1. **מתחת** — לרוב סימני הניקוד
2. **דגש** — במרכז האות
3. **מעל** — חולם / נקודת שין

זה 27×3 במקום מאות צירופים.

## שלבים

```bash
cd tools/nikud

# 1) חד־פעמי: הזרקת גליפי ניקוד מ-Rubik לגופן העבודה
py prepare_marks.py

# 2) הפעלת העורך בדפדפן
npx --yes serve .

# פתחו http://localhost:3000/editor.html
# (או את הפורט ש-serve מדפיס)
```

בעורך:
- בחרו אות → בחרו סוג עוגן → גררו את העיגול הירוק
- **שמירה** מורידה `anchors.json`
- שימו את הקובץ בתיקייה הזו (החליפו את הקיים)

```bash
# 3) בניית GPOS
py build_gpos.py

# 4) אחרי שאתם מרוצים — התקנה לאפליקציה
py build_gpos.py --install
# ואז העלו את ?v= של הגופן ב-CSS, npm run build, ופרסו
```

## קבצים

| קובץ | תפקיד |
|------|--------|
| `prepare_marks.py` | מעתיק גליפי ניקוד מ-Rubik → `work/agol-work.ttf` |
| `editor.html` | ממשק גרירה |
| `anchors.json` | מיקומי העוגנים שערכת |
| `build_gpos.py` | בונה GPOS וכותב ל־`app/public/fonts/agol.*` |
| `font-meta.json` | מטא־דאטה לעורך (נוצר ב-prepare) |

## הערות

- העורך שומר גם ל־`localStorage` (גיבוי בין רענונים).
- גליפי הניקוד מגיעים מ־Rubik (צורת הסימן); המיקום על כתב העגול — שלכם.
- אם סימן נראה גדול/קטן מדי יחסית לאות — אפשר בהמשך להקטין את מתארי הניקוד ב־prepare; המיקומים יישארו.
